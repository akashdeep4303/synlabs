Invoice API

Base URL: https://api.nimbusledger.com/v1. Authenticate with a bearer API key. Keys are workspace-scoped.

Rate limits

The invoice endpoints allow 120 requests per minute per API key, with a burst of 20 concurrent in-flight requests. Exceeding the limit returns HTTP 429 with a Retry-After header in seconds.

Scale plan workspaces may request a raised cap; Starter and Growth cannot.

Create invoice

POST /invoices accepts JSON with fields entity_id, customer_id, currency, lines[], and optional due_on. Draft invoices do not increment journal-line usage. Posting an invoice creates an AR journal and counts toward the monthly line quota.

Idempotency

Pass header Idempotency-Key (UUIDv4). Keys are remembered for 24 hours. Replays return the original response, including errors.

Webhooks

Invoice posted, voided, and paid events are delivered to the workspace webhook URL. Failed deliveries retry 8 times with exponential backoff starting at 4 seconds (4, 8, 16, …). After 8 failures the event is dead-lettered and visible in the developer console for 14 days.
